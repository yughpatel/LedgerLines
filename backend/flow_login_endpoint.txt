POST /auth/login
Input: UserLogin (email + password)

1. Query: Find user by email
   → If not found: raise 401

2. Verify: Check password using verify_password()
   → If doesn't match: raise 401

3. Generate: Create JWT token with user.id inside it

4. Return: Token to client (they'll store it, send it with future requests)

POST /auth/login
Input: UserLogin (email + password)
Output: {"access_token": "...", "token_type": "bearer"}

Steps:
1. Query database for user with that email
2. If user not found → raise HTTPException 401 with "Invalid email or password"
3. If user found → verify password using verify_password()
4. If password wrong → raise HTTPException 401 with "Invalid email or password"
5. If password correct → call create_access_token({"sub": str(user.id)})
6. Return {"access_token": token, "token_type": "bearer"}
